Lua API

Ra Engine's game logic layer. Drop a .lua script in scripts/, point the engine at it, and the full engine API is available as the global table engine. Changes to the script hot-reload live — no recompile needed.

Game code is isolated. Lua scripts never include Vulkan, GLFW, or engine headers. All engine access goes through the engine global. This lets you iterate on game logic independently of the graphics pipeline.

01. Script Contract

Every Ra Engine Lua script must define these global functions. The engine calls them automatically.

function init() required

Called once when the script first loads, and again on every hot-reload. Use this to look up object IDs with engine.find_object(), set initial positions, and read any persisted state from engine.get_var().

Do not cache object IDs across hot-reloads in module-level Lua variables — the scene may have changed. Always re-discover them inside init().

function update(dt) required

Called every frame before rendering. dt is the frame delta time in seconds (capped; safe for physics). All game logic, input polling, scoring, and object movement goes here.

dtfloatSeconds elapsed since the last frame. Capped to prevent physics explosion on lag spikes.
function shutdown() required

Called on engine exit (before Vulkan teardown). Save any game state that must survive process restart using engine.set_var(). This is your last chance to write persistent data.

function get_status_line() → string optional

Return a short string shown in the engine's terminal status area (bottom line). Called every frame. Return "" to show nothing. Keep it under ~80 characters for clean display.

02. Hot-Reload

Every frame, the engine stat()s the script file. If the modification time has changed, it automatically:

  1. Calls shutdown() on the current Lua state
  2. Destroys the old lua_State
  3. Opens a fresh state, re-binds the full engine API
  4. Runs the script file
  5. Calls init() again
Lua variables do not survive hot-reload. Any local Lua state (local variables, tables, closures) is destroyed when the lua_State is torn down. Only values written to engine.set_var() survive — they live in C++ and are unaffected by Lua restarts.

If the reloaded script has a syntax or runtime error, the engine keeps the previous working state and suppresses further reload attempts until the file is saved again.

03. Persisting State

Use engine.set_var() / engine.get_var() for any value that must survive hot-reloads, level transitions, or be shared between update() and shutdown().

function init()
    -- Read back values saved from a previous session or hot-reload
    score       = engine.get_var("game.score",       0.0)
    peak_height = engine.get_var("game.peak_height", 0.0)
    level       = engine.get_var("game.level",       1.0)
end

function shutdown()
    -- Write everything back before the engine exits
    engine.set_var("game.score",       score)
    engine.set_var("game.peak_height", peak_height)
    engine.set_var("game.level",       level)
end
Namespace your keys. Prefix all variable keys with your game name (e.g. "launch_up.score") to avoid collisions if multiple scripts are used across levels.

04. Camera

The camera is the player in first-person mode. Moving the camera moves the player. Physics and collision are resolved relative to the camera position.

engine.get_camera_position() → x, y, z get

Returns the camera's world-space position as three separate floats. Y is vertical.

local x, y, z = engine.get_camera_position()
engine.print_status("Height: " .. string.format("%.1f", y) .. "m")
engine.set_camera_position(x, y, z) set

Teleports the camera (and player) to the given world-space position. Used for respawning and level start placement. Call engine.set_vertical_velocity(0.0) immediately after to clear any falling momentum.

local cx, cy, cz = engine.get_checkpoint()
engine.set_camera_position(cx, cy, cz)
engine.set_vertical_velocity(0.0)
engine.get_camera_forward() → x, y, z get

Returns the normalised camera look direction. Useful for shooting projectiles, detecting what the player is looking at, or directional movement in non-physics contexts.

engine.get_camera_right() → x, y, z get

Returns the normalised camera right vector (perpendicular to forward, in the horizontal plane). Use with forward for strafe-relative logic.

05. Physics

engine.get_physics_state() → table get

Returns a table describing the player's current physics state.

is_groundedboolTrue if the player is standing on solid geometry this frame.
is_jumpingboolTrue during the upward arc of a jump.
vertical_velocityfloatCurrent vertical speed in m/s. Negative = falling.
local ps = engine.get_physics_state()
if ps.is_grounded then
    -- can jump
end
engine.set_vertical_velocity(v) set

Directly sets the player's vertical velocity. Use to trigger a jump (8.5) or cancel falling momentum (0.0) on respawn.

vfloatVelocity in m/s. Positive = upward. Engine gravity is −18.0 m/s².
-- Trigger jump from Lua
local ps = engine.get_physics_state()
if ps.is_grounded then
    engine.set_vertical_velocity(8.5)
end

06. Input

engine.get_input() → table get

Returns a snapshot of the current frame's input state. Read this once per update() — it's valid for the duration of that call.

key_downtableIndexed by GLFW key code. true if the key is currently held. Use for continuous actions (movement, holding fire).
key_just_pressedtabletrue only on the single frame the key transitioned from up to down. Use for discrete actions (jump, interact, menu).
mouse_delta_xfloatMouse horizontal movement this frame in pixels.
mouse_delta_yfloatMouse vertical movement this frame in pixels.
local inp = engine.get_input()

-- Held key — movement
if inp.key_down[KEY_W] then
    -- move forward
end

-- One-shot key — jump
if inp.key_just_pressed[KEY_SPACE] then
    engine.set_vertical_velocity(8.5)
end

-- Level advance
if inp.key_just_pressed[KEY_N] then
    engine.load_scene("scenes/launch_up_level2.gltf")
end
key_just_pressed is edge-triggered. It is true for exactly one frame. Do not check it inside a loop or across multiple update() calls — you will miss it. Always read input once at the top of update().

07. Time

engine.get_time() → double get

Returns wall-clock seconds as a double. Use for animations, pulse effects, and time-based events. Always increasing — not affected by pause or frame rate.

local t = engine.get_time()
local pulse = (math.sin(t * 2.0 * math.pi * 1.5) + 1.0) * 0.5
engine.set_object_emissive(glow_id, 0.0, 1.0, 0.9, 2.0 + pulse * 3.0)
engine.get_delta_time() → float get

Returns the same dt that was passed to update(dt). Provided as a convenience for helper functions that don't receive dt as a parameter.

08. Scene Objects

Scene objects are identified by a uint32 ID assigned at load time. IDs are stable within a scene session but must be re-acquired after a scene reload or hot-reload — always call engine.find_object() inside init().

ID 0 means not found. engine.find_object() returns 0 when no object with that name exists. Always check before using.

Transform

engine.find_object(name) → id query

Looks up a scene object by its GLTF node name. Returns the integer ID, or 0 if no object with that name exists in the current scene.

namestringExact GLTF node name (case-sensitive, matches ra_label in the scene file).
function init()
    goal_id = engine.find_object("goal_pad")
    if goal_id == 0 then
        engine.print_status("WARNING: goal_pad not found in scene")
    end
end
engine.object_exists(id) → bool query

Returns true if id is non-zero and present in the current scene. Useful as a guard before transform calls.

engine.get_object_position(id) → x, y, z get

Returns the world-space position of the object's transform origin as three floats.

engine.set_object_position(id, x, y, z) set

Moves the object to the given world-space position. Internally rewrites vertex data, re-uploads via staging, and rebuilds the BLAS/TLAS. The rebuild is transparent — call freely each frame for moving platforms, hazards, etc.

iduint32Object ID from find_object().
x, y, zfloatTarget world-space position.
engine.get_object_rotation(id) → x, y, z get

Returns Euler rotation in degrees (YXZ order, matching the Ra Engine editor).

engine.set_object_rotation(id, x, y, z) set

Sets Euler rotation in degrees (YXZ order). Use for rotating hazard platforms, spinning collectibles, or animated scene elements.

-- Rotate a hazard platform 45°/sec on Y axis
spinner_angle = (spinner_angle + 45.0 * dt) % 360.0
engine.set_object_rotation(spinner_id, 0.0, spinner_angle, 0.0)
engine.get_object_scale(id) → sx, sy, sz get

Returns the current scale of the object as three floats. Default scale is 1, 1, 1. Minimum per-axis value enforced by the engine: 0.01.

engine.set_object_scale(id, s)  or  engine.set_object_scale(id, sx, sy, sz) set

Sets object scale. Pass one value for uniform scale; pass three for non-uniform. Minimum component is 0.01.

engine.set_object_scale(crystal_id, 2.0)              -- uniform 2×
engine.set_object_scale(platform_id, 3.0, 0.5, 3.0)  -- wide flat slab

Visual

engine.set_object_emissive(id, r, g, b [, intensity]) set

Sets the emissive colour and intensity of an object at runtime. Drives RTX global illumination — nearby geometry will be lit by the emissive surface. intensity defaults to 1.0.

r, g, bfloatEmissive colour channels in [0, 1].
intensityfloatMultiplier. 0.0 = off, 1.0 = normal, >1.0 = boosted. Values above ~6.0 will saturate nearby surfaces white.
-- Cyan pulse effect on goal pad glow
local p = (math.sin(engine.get_time() * 3.0) + 1.0) * 0.5
engine.set_object_emissive(glow_id, 0.0, 1.0, 0.9, 2.0 + p * 3.0)

-- Turn emissive off
engine.set_object_emissive(glow_id, 0.0, 0.0, 0.0, 0.0)
engine.set_object_visible(id, visible) set

Shows or hides an object in the ray-traced scene. Hidden objects are collapsed to a degenerate position in the BVH so no rays can hit them. Use for reveal mechanics, goal pads, and collectibles.

Note: Physics collision is currently unaffected by visibility — hidden objects still block the player. This is a known engine limitation (tracked).

Collision & Triggers

engine.get_object_aabb(id) → min_x, min_y, min_z, max_x, max_y, max_z get

Returns six floats describing the world-space axis-aligned bounding box of the object. Returns a degenerate (zero-size) AABB if the ID is invalid.

engine.get_player_aabb() → min_x, min_y, min_z, max_x, max_y, max_z get

Returns the player's world-space AABB (a capsule approximation centred on camera position). Use with get_object_aabb for custom trigger logic.

engine.player_overlaps_object(id) → bool query

Convenience function. Returns true if the player's AABB overlaps the object's AABB this frame. The primary method for trigger zones, checkpoints, and goal detection.

if engine.player_overlaps_object(goal_id) then
    state = "finished"
    engine.print_status("★ LEVEL COMPLETE!")
end

09. Scene Queries

engine.find_objects_by_prefix(prefix) → table of IDs query

Returns a 1-indexed Lua table of all object IDs whose GLTF node name starts with prefix. Returns an empty table if no objects match. Use for bulk operations on named groups of objects (e.g. all "platform_hazard_" nodes).

local hazards = engine.find_objects_by_prefix("platform_hazard_")
engine.print_status("Found " .. #hazards .. " hazard platforms")

for i, id in ipairs(hazards) do
    engine.set_object_emissive(id, 1.0, 0.2, 0.0, 2.0)
end
engine.get_all_object_names() → table of strings query

Returns a 1-indexed Lua table of every GLTF node name in the current scene. Useful for debugging scene layout in init().

local names = engine.get_all_object_names()
engine.print_status("Scene has " .. #names .. " objects")

10. Scene Loading

engine.load_scene(path) action

Requests a scene transition. The new GLTF is loaded at the start of the next frame — the current update() call finishes cleanly first. After the load completes, the engine calls init() again so the script can re-discover objects in the new scene.

pathstringPath to the GLTF file, relative to the working directory (e.g. "scenes/launch_up_level2.gltf").
-- Level progression table
local LEVELS = {
    "scenes/launch_up_tutorial1.gltf",
    "scenes/launch_up_level1.gltf",
    "scenes/launch_up_level2.gltf",
}
local current = 1

-- On level complete:
current = current + 1
if current <= #LEVELS then
    engine.set_var("game.level", current)
    engine.load_scene(LEVELS[current])
    -- init() will be called automatically after load
end
Score persists across load_scene. Game variables written with engine.set_var() before calling load_scene() are available when init() runs in the new scene.

11. Checkpoints

The engine stores a single world-space respawn position. Update it as the player climbs past tier thresholds.

engine.set_checkpoint(x, y, z) set

Sets the respawn position. Call when the player reaches a new height tier or crosses a trigger zone.

engine.get_checkpoint() → x, y, z get

Returns the current respawn position. Use in the dead-state respawn handler alongside set_camera_position().

local function respawn()
    local cx, cy, cz = engine.get_checkpoint()
    engine.set_camera_position(cx, cy, cz)
    engine.set_vertical_velocity(0.0)
    state = "exploring"
end

12. Game Variables

A simple float key-value store that lives in C++ and survives hot-reloads, scene transitions, and shutdown() / restart cycles within a session.

engine.set_var(key, value) set

Stores a float value under an arbitrary string key.

keystringArbitrary identifier. Prefix with your game name to avoid collisions.
valuefloatValue to store. All game state must be encodable as floats (use 0/1 for booleans, integer indices for levels).
engine.get_var(key, default) → float get

Retrieves a stored value. Returns default if the key has never been set.

keystringThe key to look up.
defaultfloatFallback value if the key doesn't exist yet.

13. HUD & Status

engine.print_status(text) action

Prints a line to the engine's terminal status area. Transient — overwritten on the next call. Use for debug output, event notifications (checkpoint reached, level complete), and tutorial prompts.

engine.set_hud_data(score, height) set

Pushes score and height values to the engine HUD overlay. Call every frame while the game is running to keep the display current.

scorefloatCurrent score in points.
heightfloatHeight gained from spawn in metres (not absolute Y). Displayed as progress metric.
-- In update_exploring():
local _, cy, _ = engine.get_camera_position()
if cy > peak_height then
    peak_height = cy
    score = (peak_height - spawn_y) * 100.0
end
engine.set_hud_data(score, peak_height - spawn_y)

15. Minimal Complete Script

A stripped-down example showing all required entry points and the most common patterns.

-- scripts/my_game.lua — minimal Ra Engine Lua script

local DEATH_PLANE = -5.0
local state       = "exploring"
local respawn_t   = 0.0
local goal_id     = 0
local score       = 0.0
local spawn_y     = 0.0
local peak_y      = 0.0

function init()
    local _, y, _ = engine.get_camera_position()
    spawn_y = y
    peak_y  = engine.get_var("game.peak", y)
    score   = engine.get_var("game.score", 0.0)

    goal_id = engine.find_object("goal_pad")
    engine.set_checkpoint(0.0, y, 5.0)
    engine.print_status("Ready — climb to the goal!")
end

function update(dt)
    if state == "exploring" then
        local _, cy, _ = engine.get_camera_position()

        if cy > peak_y then
            peak_y = cy
            score  = (peak_y - spawn_y) * 100.0
            engine.set_var("game.peak",  peak_y)
            engine.set_var("game.score", score)
        end
        engine.set_hud_data(score, peak_y - spawn_y)

        if goal_id ~= 0 and engine.player_overlaps_object(goal_id) then
            state = "finished"
            engine.print_status("★ LEVEL COMPLETE!  Score: " .. score)
        end

        if cy < DEATH_PLANE then
            state     = "dead"
            respawn_t = 1.5
        end

    elseif state == "dead" then
        respawn_t = respawn_t - dt
        if respawn_t <= 0.0 then
            local cx, cy, cz = engine.get_checkpoint()
            engine.set_camera_position(cx, cy, cz)
            engine.set_vertical_velocity(0.0)
            state = "exploring"
        end

    elseif state == "finished" then
        local inp = engine.get_input()
        if inp.key_just_pressed[KEY_R] then
            score = 0.0; peak_y = spawn_y; state = "exploring"
            engine.set_var("game.score", 0.0)
            engine.set_checkpoint(0.0, spawn_y, 5.0)
            engine.set_camera_position(0.0, spawn_y, 5.0)
            engine.set_vertical_velocity(0.0)
        elseif inp.key_just_pressed[KEY_N] then
            engine.load_scene("scenes/launch_up_level2.gltf")
        end
    end
end

function shutdown()
    engine.set_var("game.score", score)
    engine.set_var("game.peak",  peak_y)
end

function get_status_line()
    if state == "exploring" then
        return "Height: " .. string.format("%.1f", peak_y - spawn_y) .. "m  |  Score: " .. score
    elseif state == "dead" then
        return "Respawning..."
    else
        return "★ COMPLETE — R=restart  N=next level"
    end
end
